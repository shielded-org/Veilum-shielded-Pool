# Veilum Wallet Extension

Chrome MV3 popup wallet for private stablecoin transfers on Stellar.

**Full documentation:** [docs/wallet-extension.md](../../docs/wallet-extension.md)

## Quick start

```bash
# from privacy/
npm install
npm run build:extension
```

Load `dist/` as an unpacked extension in `chrome://extensions`.

```bash
npm run dev:extension   # UI dev server only
```
